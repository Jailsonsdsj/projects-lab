# Design system

The UI is the Claude Design bundle (`docs/design/`) turned into code. See every component in every variant and state at **`/dev/ui`** (not in navigation), at phone and tablet widths.

## Where things live

| File | What | Edit? |
|---|---|---|
| `docs/design/*.html` | The bundle (D-00). Unpack with `pnpm design:extract` | Replace with a new export |
| `docs/design/tokens.css`, `components.css` | Readable copies of the bundle's CSS, written by `pnpm design:extract` | Never |
| `packages/web/src/styles/tokens.css` | The tokens: bundle §1 and §6 inside `@theme static`, §2–§5 plain. Values identical to the bundle | Only to follow a new bundle |
| `packages/web/src/styles/components.css` | The bundle's component CSS minus its canvas-only `.is-hover` / `.is-pressed` / `.is-focus` selectors, with its element resets as `.pl :where(tag)` so components' own colours and fonts win. Generated by `pnpm design:extract` | Never |
| `packages/web/src/styles/app-components.css` | What the canvas couldn't draw: `<dialog>` and popover integration, exit animations, the shell layout, toast region, real `<img>` tiles, native states the bundle only forced | Yes, tokens only |
| `packages/web/src/components/ui/icons.ts` | The bundle's 43 icons, verbatim, plus `sidebar` (the course reader's outline toggle, drawn to the same grid and stroke; the bundle has none) | Copy new ones from the bundle |
| `packages/web/src/components/ui/` | The components below; `index.ts` exports them | Yes |
| `packages/web/src/dev/catalog.tsx` | `/dev/ui`'s examples; a test fails if a component has no entry | With every component |

## Rules

- **Tokens only.** No literal colour, px size, duration or curve outside `tokens.css`; `scripts/check-tokens.sh` (in `pnpm lint` and `pnpm lint:tokens`, self-test first) fails on hex and colour functions, px/rem sizes, React style numbers, CSS durations, easing curves and z-index. Comments count too: name the token instead. Components use the bundle's classes; layout uses Tailwind utilities generated from the tokens (`p-3`, `gap-2`, `text-ink-muted`).
- **The lab accent** comes from `data-lab` on `<html>` (set by the shell) or on an element (LabCard, LabSwitcher options). Components read `--color-lab-*` only and never branch on the lab. In Tailwind: `bg-(--color-lab-accent)`.
- **No z-index.** Sheet and Dialog are native `<dialog>` (top layer, `::backdrop` scrim); menus are `popover`.
- **Timings in JS** come from tokens through `cssDurationMs("--duration-…")`, never a number in code.
- **Breakpoints:** CSS uses `@variant tablet` / `wide` (Tailwind) and utilities like `tablet:p-4`. The rare JS choice (Sheet vs popover) uses `useMinWidth("--breakpoint-…")`. Phone < 768, tablet 768–1279 (compact rail < 1024), wide ≥ 1280 centred at `--size-app-max`.
- **Markup follows the bundle**, including small things that carry meaning (the space before a count is part of the accessible name).
- **Errors, offline, empty.** A screen reads through `ReadView` (`core/ReadView.tsx`; `useRead` underneath): `load` resolves to `null` for "no data yet" (EmptyState, saying what to do next) and rejects only when the read failed (ErrorState with Retry; `offline` when the request never got an answer). A failure never renders as "nothing here yet". It reads again when the app returns to the foreground or comes back online (data Claude wrote meanwhile appears without navigating); a failed background read keeps what's on screen. Every route sits under one error boundary (`core/RouteError.tsx`), so a screen that throws shows an error inside the shell, an unknown path shows Not found, and React Router's default page never appears.
- **Closed overlays:** the bundle's `display: flex` beats the UA's hiding of closed dialogs and popovers; `app-components.css` restores it. Keep that rule when adding an overlay.

## Adding a component

1. Find it in `docs/design/components.css` and its markup in the bundle (`pnpm design:extract`, then the unpacked pages).
2. Build it on the bundle's classes; anything the canvas couldn't draw goes in `app-components.css`.
3. Export it from `components/ui/index.ts`, add it to `src/dev/catalog.tsx` (every variant × state), and add a row above (or name it on the Helpers line if it renders nothing). `src/dev/inventory.test.ts` fails on any export missing here, any row or helper no longer exported, and a built component still listed as "not built yet".
4. Test behaviour, not snapshots.
